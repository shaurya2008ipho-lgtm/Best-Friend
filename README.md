# A Little Thank You — For You ♡

A dependency-free, scrapbook-style appreciation website for a best friend, now with an Our Friendship Journal update.

## Main website
- Warm paper texture and handwritten typography
- Floating doodles, sticky notes and scrapbook-style cards
- Hand-drawn portrait sketch and animated drawing sequence
- Responsive layout for desktop and mobile
- Prominent **NEW — Our Friendship Journal** feature on the homepage

## Friendship Journal update
- `journal.html` contains the two journal choices: **Memories** and **Meaningful messages**.
- `memories.html` is the new moonlit memories experience, with a glowing full moon, animated stars, visible wind trails and gently swaying leafy branches.
- The first memory, **Our First Meeting**, opens an expanded note with the story text.
- Meaningful messages is shown as **Coming soon**; its content has not been built yet.
- `friendship-pages.css` and `friendship-pages.js` style and power the new pages.

## Music
The homepage song and its playback JavaScript have been removed, as requested. No audio file is required.

## Run locally
Open `index.html` directly or, preferably, right-click it in VS Code and choose **Open with Live Server**. No npm install is required. Keep all files and the `assets` folder together.

## Privacy / reference image
The original reference photograph is not included. The website uses the hand-drawn portrait artwork stored in `assets/portrait-sketch.jpg`.
