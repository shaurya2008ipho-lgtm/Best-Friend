# A Little Thank You — For You ♡

A dependency-free, scrapbook-style thank-you website for a best friend.

## Included
- Warm paper texture and handwritten typography
- Floating doodles, sticky notes and scrapbook-style cards
- Hand-drawn portrait sketch
- Animated hand + pencil drawing sequence
- Progress indicator and “Draw it again” replay button
- Responsive layout for desktop and mobile

## Privacy / reference image
The original reference photograph is **not included or displayed** in this version. The website only uses the hand-drawn portrait artwork and decorative sketch elements.

## Run
Open `index.html` directly, or use VS Code Live Server for the smoothest local experience. No npm install is required.
